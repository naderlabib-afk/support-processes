🔧 Support Process Finder

📌 Overview

Support Process Finder is a lightweight web application designed for technical support teams to quickly search, view, and manage workflow processes.

It allows agents to:

🔍 Search processes using keywords

📂 Filter by category (Contract, Location, Customer, etc.)

⭐ Save frequently used processes as favorites

📧 Share processes via email

📋 Copy process steps for tickets or communication

An integrated Admin Panel enables process management without editing raw JSON files.


✨ Features

🔍 Smart Search: Search by issue, process steps, category, or machine type

Instant filtering as you type

🗂 Category Filters: Quickly narrow results using predefined categories

⭐ Favorites: Save frequently used processes, Stored locally in your browser

📤 Actions

Email: Share a process via email

Copy: Copy steps to clipboard

Favorite: Save for quick access

🛠 Admin Panel: Add new processes / Edit existing ones / Delete entries / Export data as JSON

Protected with a password

🌙 Dark Mode: Toggle between light and dark themes

🔐 Admin Access: with password

💡 How to Use

Open the HTML file in any browser, Use the search bar or category buttons to find a process, Use action buttons to copy, email, or favorite

(Optional) Open Admin panel to manage processes

⚙️ Requirements

Modern web browser (Chrome, Edge, Firefox)

Internet connection (for loading remote JSON)


🚀 Notes

No installation needed
Fully client-side
Favorites are saved per browser (localStorage)

👥 Intended Use

Designed for small to medium technical support teams needing:

Fast access to procedures

Consistent handling processes

Easy maintainability
